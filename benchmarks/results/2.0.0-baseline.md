# Baseline: PulseFlow 2.0.0

Run on 2026-09-26 with the first version of the benchmark suite, before the 2.1 dispatch optimizations.
Kept as the reference point to measure later versions against.

Notes:
- Machine: AMD Ryzen 5 3600, Windows 11, .NET 10.0.11 (desktop, not an isolated benchmark machine).
- "Startup" here was measured *warm* (in-process, JIT and reflection caches already populated). It is **not** a cold
  start and must not be used to compare startup against Mediator; later runs add a real cold-start job.
