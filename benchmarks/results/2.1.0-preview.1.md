# PulseFlow 2.1.0-preview.1

Run on 2026-09-26 after the 2.1 dispatch optimizations (single-lookup fast path, independent caching of general and
command/query behavior lists, no array copy in `Publish`). Same machine as the [2.0.0 baseline](2.0.0-baseline.md):
AMD Ryzen 5 3600, Windows 11, .NET 10.0.11 (desktop, not an isolated benchmark machine).

Compared with the baseline: Send 56.6 → 52.4 ns, Publish 82.8 → 60.2 ns (128 → 88 B). Send + behaviors unchanged
(its remaining cost is resolving transient behaviors and building the delegate chain); the run below still used
transient behaviors only, singleton behaviors are measured from the next run on.

Startup now has a real **ColdStart** job (new process per measurement) next to the **Warm** job.
BenchmarkDotNet's `MinIterationTime` warning on ColdStart is expected: each measurement is a single first call.
